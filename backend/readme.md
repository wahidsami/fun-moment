# FunMoment

A multi-vendor on-demand service marketplace.

**Owner:** funmoment.sa

## Tech Stack

- PHP 8.1+
- Laravel 10
- MySQL
- Livewire 2
- Laravel Mix (Webpack)

## Features

- Service listing and booking with scheduling
- Multi-vendor seller/buyer system
- 15+ payment gateways
- Blog/CMS with page builder
- REST API with Sanctum auth
- Multi-language support
- Support ticket system
- Social login (Google, Facebook)
